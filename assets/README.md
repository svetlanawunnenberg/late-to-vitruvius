# Illustrations go here

Drop PNG files with these **exact names** into this folder and the game picks
them up automatically. Nothing in the code needs to change, and any file you
have not made yet keeps its hand-drawn version.

| File name | What it shows | Size | Notes |
|---|---|---|---|
| `chariot-biga.png` | Two-horse chariot, side view | ~800×500 | **Facing right.** Wheels sitting on the bottom edge of the image. |
| `chariot-quadriga.png` | Four-horse chariot | ~800×500 | Same view and same eye-level as the biga, so they sit together. |
| `chariot-carpentum.png` | Covered two-wheeled cart | ~800×500 | Same again. |
| `pomegranate.png` | One pomegranate | ~256×256 | Centred, a little margin all round. |
| `scroll.png` | An open, unrolled, **blank** parchment | ~1200×800 | Text is drawn over it, so leave the middle empty. |
| `vitruvius.png` | A figure or a bust | ~600×800 | For the arrival screen. |
| `road.png` | Roman street backdrop — cypresses, an aqueduct, a wall | ~2400×600 | Must **tile left to right**: the right-hand edge has to meet the left-hand edge without a seam, because it scrolls in a loop. |

## Rules for all of them

- **Transparent PNG.** No white box behind the subject.
- **One consistent style across the whole set.** Line engraving suits the
  design best — it matches the plate frame, the dimension annotations and the
  typography. Flat colour works too, as long as everything matches.
- **Keep each file under about 400 KB.** These load on phones over mobile data.
  Anything over 1 MB will make the game feel slow.
- **No photographs of real projects**, and nothing from the office drives. This
  repository is public.
